# Agenda RT · tablet

Versión para tablet de la Agenda Jurídica de TR Abogados. Funciona sin internet; los datos se guardan solo en la tablet.

**Instalar:** abre https://elsadiko-pantanoreckordz.github.io/agenda-trabogados/ en Chrome → menú ⋮ → «Instalar app».

Aquí solo está el código de la app; ningún expediente ni dato del despacho se sube a este sitio.
